# Sistema de Controle de Pendências

Sistema desktop simples feito em Python com Tkinter para cadastro e controle de pendências, com tela de login.

## Funcionalidades

- Tela de login (usuário/senha)
- Tela principal do sistema
- Cadastro de nova pendência (descrição + responsável)

## Tecnologias

- Python 3
- Tkinter (interface gráfica)
- SQLite (planejado para persistência dos dados)

## Como executar

```bash
python sistema_pendencias.py
```
